# Destrave seu Brilho em 5 dias

Landing page estática em português para o desafio de cinco manhãs ao vivo, às 7h, com investimento de R$ 37,90.

## Arquivo principal

- `index.html`: página responsiva com vídeo reservado, benefícios, dificuldades da audiência, entregáveis, plano dos cinco dias, oferta, depoimentos e dúvidas frequentes.

## Antes de publicar

1. Conecte os botões de inscrição ao checkout oficial.
2. Troque os depoimentos de exemplo por relatos reais autorizados.
3. Inclua datas, informações sobre gravações e outros detalhes da oferta quando estiverem definidos.
4. Adicione o vídeo explicativo ao espaço reservado no topo da página.

O projeto não usa framework nem dependências de build. Abra `index.html` no navegador ou publique a pasta como site estático.
